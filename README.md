# 내 일기 📔

서버 없이, 내 폰 브라우저 안에만 저장되는 개인 일기장입니다.
사진과 동영상을 함께 넣을 수 있고, 인터넷이 없어도 열립니다.

- 설치할 앱도, 가입할 계정도 없습니다.
- 일기 내용은 이 브라우저의 저장소(IndexedDB)에만 들어갑니다. 어디로도 전송되지 않습니다.
- 나중에 마음이 바뀌면 일기 한 편을 **혼자 열리는 HTML 파일**로 내보내 다른 사람에게 보여줄 수 있습니다.

---

## 1. 폰에서 여는 방법

### 가장 편한 방법 — 무료 정적 호스팅에 올리기 (권장)

폰의 크롬에서 `파일`을 직접 열면 기기에 따라 저장이 되지 않을 수 있습니다.
주소(`https://…`)로 열어야 홈 화면 추가와 오프라인 저장이 제대로 동작합니다.
GitHub Pages는 무료이고 5분이면 됩니다. (계정과 결제는 직접 하셔야 합니다.)

1. <https://github.com> 에 로그인 → 오른쪽 위 **+ → New repository**
2. Repository name 에 `diary` → **Public** → **Create repository**
3. **uploading an existing file** → 이 폴더(`projects/diary`) 안의 파일과 폴더를 **전부** 끌어다 놓기
   (`index.html`, `css`, `js`, `icons`, `manifest.webmanifest`, `sw.js` — 폴더째 끌어다 놓으면 됩니다)
4. **Commit changes**
5. 저장소의 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, 폴더: **/(root)** → **Save**
6. 1~2분 뒤 `https://내아이디.github.io/diary/` 를 폰 크롬으로 열기

> 주소가 바뀌면(예: 다른 아이디로 다시 올리면) 브라우저는 다른 곳으로 보고 **이전에 쓴 일기가 보이지 않습니다.**
> 그럴 때는 아래 **백업 → 가져오기**로 옮기면 됩니다.

### 지금 이 컴퓨터에서 바로 보기

폴더에서 아래 명령을 실행하고 브라우저에서 <http://localhost:8000> 을 엽니다.
(파이썬이 없다면 폴더의 `index.html` 을 더블클릭해도 열립니다. 단, 일부 브라우저에서는 저장이 안 될 수 있습니다.)

```bash
cd projects/diary
python3 -m http.server 8000
```

## 2. 홈 화면에 추가 (앱처럼 쓰기)

폰 크롬에서 주소를 연 뒤 **오른쪽 위 ⋮ → 홈 화면에 추가**.

- 주소창 없이 전체 화면으로 열립니다.
- 한 번 열어 두면 **인터넷이 없어도** 열립니다(서비스 워커가 화면을 저장해 둡니다).
- 앱 안의 [설정 → 홈 화면에 추가]에 설치 버튼이 보이면 그걸 눌러도 됩니다.

## 3. 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 오늘 일기 쓰기 | 오른쪽 아래 **✎ 쓰기** 버튼 |
| 기분 고르기 | 😊 🙂 😌 😐 😔 😤 😴 🤒 중 하나 (다시 누르면 해제) |
| 사진 넣기 | **📷 사진** (여러 장 한 번에 선택 가능, 최대 20장) |
| 동영상 넣기 | **🎬 동영상** (최대 2개) |
| 태그 | `산책, 가족` 처럼 쉼표로 구분 |
| 저장 | 오른쪽 위 **저장** |
| 일기 보기 | 목록에서 카드 누르기 |
| 고치기 / 지우기 | 일기 화면 오른쪽 위 **⋯** |
| 찾기 | 아래 **검색** 탭 — 제목·본문·태그에서 찾고, 검색어는 노란색으로 표시 |
| 날짜별로 보기 | 아래 **달력** 탭 — 점이 있는 날에 일기가 있습니다 |
| 글 쓸 때 나가기 | 왼쪽 위 **✕** — 저장하지 않았다면 물어봅니다 |

- 날짜는 처음에 **오늘**로 채워집니다. 지난 날 일기도 날짜를 바꿔 쓸 수 있습니다.
- 달력에서 날짜를 고르고 **[이 날 일기 쓰기]** 를 누르면 그 날짜로 시작합니다.
- 왼쪽 위 **오늘** 버튼: 오늘 일기가 있으면 열어 주고, 없으면 쓰기 화면을 엽니다.
- 폰의 **뒤로 가기**를 누르면 열려 있던 화면이 닫힙니다.

## 4. 백업과 복구 (제일 중요해요)

일기와 사진은 **이 브라우저 하나에만** 있습니다. 그러니 가끔 백업해 두세요.

### 백업하기
**설정 → 💾 백업 → 내보내기** → `내일기-백업-날짜.zip` 파일이 다운로드됩니다.

ZIP 안에는 이렇게 들어 있습니다. ZIP 압축을 풀어 사진만 꺼내 봐도 됩니다.

```
entries.json        일기 내용(제목·본문·날짜·기분·태그·사진 정보)
media/…jpg, .webm   원본 사진과 동영상
thumbs/…jpg         목록에 쓰는 작은 미리보기
README.txt          안내
```

### 다시 가져오기
**설정 → 💾 백업 → 가져오기** → ZIP 고르기 → **지금 일기에 더하기** 또는 **전부 바꾸기**

- *더하기*: 지금 있던 일기는 그대로 두고 백업의 일기를 추가합니다. 같은 일기는 더 최근 것만 남습니다.
- *전부 바꾸기*: 지금 자료를 모두 지우고 백업 내용으로 되돌립니다. (확인을 한 번 더 물어봅니다)

### 이럴 때 백업이 필요해요
- 폰을 바꿀 때 / 브라우저를 바꿀 때
- 크롬에서 **인터넷 사용 기록 삭제**를 할 때 (사이트 데이터를 지우면 일기도 지워집니다)
- 시크릿 모드로 열었을 때 (창을 닫으면 사라집니다)

## 5. 한 편만 공개하고 싶을 때

**일기 화면 → ⋯ → 공개용 HTML 파일로 내보내기**

- 사진과 동영상이 **파일 안에 통째로** 들어간 HTML 파일 하나가 만들어집니다.
- 그 파일을 카카오톡·메일로 보내면 받는 사람은 앱 없이 브라우저로 열어 볼 수 있습니다.
- 파일이 크면(20MB 이상) 메신저 전송이 막힐 수 있습니다. 그럴 땐 사진 수를 줄이거나 링크로 공유하세요.
- 나중에 링크로 보여 주고 싶다면: 그 HTML 파일을 GitHub Pages 같은 정적 호스팅에 올리면 주소가 생깁니다.
  (파일 안에 `<meta name="robots" content="noindex">` 가 있어 검색에는 잘 잡히지 않습니다. 필요 없으면 지우세요.)

공유 기능은 **서버 없이 파일로만** 동작합니다. 앱 안에 공개 주소를 만드는 기능은 없습니다.

## 6. 잠금(PIN)

**설정 → 🔒 잠금** 을 켜면 앱을 열 때 4자리 숫자를 물어봅니다.
앱을 2분 넘게 벗어났다 돌아와도 다시 잠깁니다.

> ⚠️ 이 잠금은 **화면을 가리는 수준**입니다. 일기 파일 자체를 암호화하지는 않습니다.
> 폰을 아는 사람이 브라우저 저장소를 직접 열어 보면 내용을 볼 수 있고, 비밀번호를 잊으면 되찾을 방법이 없습니다.
> 잊었을 때는 브라우저의 사이트 데이터를 지우면 되지만, 그때 **일기도 함께 지워집니다.**
> 그러니 잠금을 켜기 전에 꼭 백업해 두세요.

## 7. 데이터는 어디에 있나요?

- **이 브라우저의 IndexedDB** 에만 있습니다. (서버·클라우드 전송 없음, 로그인 없음)
- 그래서 이런 특징이 있습니다.
  - 같은 폰이라도 **다른 브라우저**(삼성 인터넷, 파이어폭스)에서는 보이지 않습니다.
  - **다른 기기**와 자동으로 맞춰지지 않습니다. → 백업 파일로 옮기세요.
  - 브라우저 데이터를 지우면 함께 지워집니다. → 백업하세요.
  - 주소(도메인)가 바뀌면 다른 저장소로 취급됩니다.
- 사진·동영상은 원본 그대로 저장합니다. 많이 쌓이면 용량을 꽤 씁니다.
  (설정 → 📊 보관 현황에서 확인할 수 있어요)

## 8. 파일 구조

```
diary/
├── index.html            화면 전체 (여기 하나만 열면 됩니다)
├── css/style.css         디자인
├── js/
│   ├── app.js            화면 그리기와 동작
│   ├── idb.js            IndexedDB 저장소
│   ├── zip.js            ZIP 만들기/풀기 (백업용)
│   ├── backup.js         백업 내보내기·가져오기
│   ├── share.js          공개용 HTML 한 파일 만들기
│   ├── media.js          사진 썸네일, 동영상 첫 장면
│   └── sha256.js         PIN 해시
├── icons/                앱 아이콘
├── manifest.webmanifest  홈 화면에 추가할 때 쓰는 정보
├── sw.js                 오프라인 저장(서비스 워커)
└── README.md             이 문서
```

- 빌드 도구가 필요 없습니다. 파일을 고치면 새로고침만 하면 반영됩니다.
- 외부 CDN·라이브러리를 쓰지 않습니다. 인터넷 없이도 모든 기능이 동작합니다.
- 화면을 고친 뒤에는 `sw.js` 의 `CACHE = 'nae-diary-v1'` 의 숫자를 올려 주세요.
  그래야 폰에 저장된 예전 화면이 새 화면으로 바뀝니다.

## 9. 자주 묻는 것

**Q. 일기가 갑자기 안 보여요.**
A. 주소가 바뀌지 않았는지, 시크릿 모드가 아닌지, 브라우저 데이터를 지우지 않았는지 확인하세요.
백업 파일이 있으면 [가져오기]로 되살릴 수 있습니다.

**Q. 사진을 넣었는데 목록에 안 보여요.**
A. 미리보기를 만드는 데 잠깐 걸립니다. 잠시 뒤 새로고침해 보세요.

**Q. 여러 기기에서 같이 쓰고 싶어요.**
A. 이 앱은 일부러 서버를 두지 않았습니다. 기기 간 동기화는 지원하지 않습니다.
대신 백업 ZIP을 옮겨서 합칠 수 있습니다(가져오기 → 지금 일기에 더하기).

**Q. 유료 결제나 계정이 필요한가요?**
A. 없습니다. hosting 을 직접 고르실 때만 그 서비스의 계정이 필요합니다.
